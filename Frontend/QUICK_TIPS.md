## ⚙️ How to Make Quick Changes

### **Change Hero Text**
Find in `index.html`:
```html
<h1 class="hero-name">I'm <span>Abhay Dubey</span></h1>
<h2 class="hero-role">Full Stack Developer</h2>
<p class="hero-description">Your description...</p>
```

### **Change Colors Globally**
Edit in `style.css`:
```css
:root {
    --primary-accent: #6366f1;      /* Change this */
    --secondary-accent: #8b5cf6;
}
```

### **Add New Skill**
Edit in `script.js`:
```javascript
{ name: 'SkillName', iconUrl: 'https://icon-url' }
```

### **Update Social Links**
Find all `href` attributes in `index.html` and update URLs.

## 🆘 Quick Troubleshooting

**Q: Images not showing?**  
A: Ensure images are in `Frontend/images/` folder and path is correct

**Q: Colors look wrong?**  
A: Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)

**Q: Mobile menu not working?**  
A: Check browser console (F12) for errors

**Q: Theme toggle not saving?**  
A: Ensure localStorage is enabled in browser
